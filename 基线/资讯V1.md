## 一、这个任务是什么

每天北京时间 07:30，由 GitHub Actions 自动生成一期《资讯》：全球视野的每日情报简报，电脑关机也能在手机上看。

## 二、V1 冻结的范围

### 内容结构（7 块）

| 块 | 数量 | 说明 |
| --- | --- | --- |
| 导语 lede | 1 | 150—250 字的全局判断，不是摘要 |
| 三分钟速览 brief | 5 | 每条 30—50 字 |
| 今日三件事 top | 3 | 1 头条 + 2 要闻，含 3 条判断 |
| 全球扫描 regions | 6 区 × 2 条 | 美国 / 欧洲 / 中东 / 亚太 / 中国 / 全球南方 |
| 被低估的信号 signals | 3 | 细节 + 为什么重要 |
| 八个板块 sections | 8 板块 × 2 条 | 宏观政策 / 市场资产 / 科技AI / 半导体 / 能源气候 / 医药 / 商业 / 科学社会 |
| 三段深读 analysis | 3 | 政治与资产 / 科技与资本 / 宏观与能源，各 4—5 段 + 反方 + 观察点 |
| 与你有关 personal | 3 | 换汇 / 房贷理财 / 工作与 AI |
| 线索追踪 threads | 3—5 | 新增 / 升级 / 待验证 / 证伪 / 缓和 |

### 技术实现

| 环节 | 实现 |
| --- | --- |
| 素材 | 16 个国际 RSS，最近 40 小时，去重后取 50 条 |
| 写稿 | DeepSeek `deepseek-chat`，三段式调用：总览 → 板块 → 深读 |
| 校验 | 结构校验 + URL 白名单（不在素材里的链接清空） |
| 兜底 | 模型失败 → 标题版，照常发布 |
| 生成 | `云版/generate.py` → `build.py` → `public/` |
| 发布 | GitHub Pages，`build_type=workflow` |
| 调度 | `.github/workflows/daily.yml`，cron `30 23 * * *`（UTC）= 07:30 CST |

### 成本与限制

- DeepSeek：约 ¥0.05—0.1 / 天
- GitHub Actions / Pages：免费（公开仓库）
- **无实时行情**：`numbers` 留空，页面显示“本期未接入行情数据”
- 仓库公开；内容为公开新闻的二次整理

## 三、V1 的质量红线

1. 不编造来源、数字、引语、链接。
2. 传闻 / 待官宣 / 已确认必须标注。
3. 观点必须可追溯到前文证据。
4. 不构成投资建议。
5. 深读三篇主题不得跑题。
