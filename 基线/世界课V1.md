# 世界课 V1 · 任务基线

- 冻结日期：2026-11-05
- 线上：<https://anding99.github.io/zixun/world/>
- 仓库：<https://github.com/anding99/zixun>（`世界课/` 目录）
- 调度：`.github/workflows/world.yml`，UTC `0 0 * * *` = 北京 08:00

这是一条**基线**：后续迭代另开 V1.1 / V2，不改 V1 的语义。

---

## 一、这是什么

给父亲和 9 岁男孩的每日通识课。不追新闻，只讲“世界为什么是这样”，以及“今晚可以问孩子什么”。

一年 52 周，一周一个主题；每天换一个栏目侧面。目标不是 365 条知识，是 52 个可以反复使用的“看世界的镜头”。

## 二、V1 冻结的结构

| 块 | 要求 |
| --- | --- |
| 今日一问 | ≤30 字，问题必须与正文同一件事 |
| answer | 140—180 字，直接回答 + 一个不显然的机制 |
| 主体 column | 5 段、每段 200—240 字：事实 → 机制 → 例子 → 反例/边界 → 推论 |
| 金句 pull | 25—35 字，可带走 |
| 世界观察 world | 3 段：发生了什么 / 机制是什么 / 被忽略的是什么；另加 80—120 字的“对理解世界有什么用” |
| 反方 counter | 140—180 字，必须是最强反方 |
| 给 9 岁的三个问题 | 3 个，不用术语、不给结论；附一个 5 分钟实验 |
| 延伸 reading | 3 条，优先素材内链接；书/论文可只写名字 |
| 长期线索 threads | 3 条，跨年跟踪 |
| 篇幅 | 正文约 1500 字，读 8 分钟 |

## 三、每周主题与栏目

栏目按星期固定：

| 周一 | 周二 | 周三 | 周四 | 周五 | 周六 | 周日 |
| --- | --- | --- | --- | --- | --- | --- |
| 机制 | 历史 | 人物 | 科学 | 现场 | 共读 | 复盘 |

V1 主题（8 个，循环使用）：

1. 稀缺与选择

3. 激励
4. 复利
5. 权力
6. 风险

> **已知缩水**：概念稿承诺 52 个主题，V1 只落地 8 个，八周一轮。扩到 52 个是 V1.1 的第一件事。

## 四、质量红线

1. 事实 / 推断 / 猜测三种语气分开。
2. 每期必须有最强的反方，不能稻草人。
3. 给孩子的部分只给问题，不给结论。
4. 不写“你应该”，不做成功学，不做育儿焦虑。
5. 链接只来自当日素材；编造的 URL 会被程序清空。

## 五、技术实现

| 环节 | 实现 |
| --- | --- |
| 素材 | 与《资讯》共用 16 个国际 RSS，最近 40 小时，取 50 条 |
| 写稿 | DeepSeek `deepseek-chat`，单次调用 + 太短重写一次（<1350 字触发） |
| 校验 | 字段校验 + URL 白名单 + 字数检查 |
| 兜底 | 失败则发“今日一问 + 三条原始报道”，不空窗 |
| 构建 | `世界课/build_world.py` → `站点/world/`，与《资讯》同一仓库、同一次 Pages 发布 |
| 版式 | 纸色 + 宋体 + 墨蓝，`世界课/资源/world.css`，独立于《资讯》 |

## 六、成本与限制

- DeepSeek：约 ¥0.05—0.1 / 天（一次或两次调用）
- GitHub Actions / Pages：免费
- 世界观察依赖当天 RSS 是否有合适的国际事件；没有时话题会偏弱
- `github.io` 在国内访问偶有超时；需要时可加 Cloudflare 镜像
- 无插图、无音频
