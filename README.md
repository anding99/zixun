# 资讯 · 个人情报台

一份每天更新的个人资讯页：**全球视野 + 深度分析 + 全领域覆盖**，电脑和手机都能打开。

**公网（手机 / 任意网络）：<https://continuing-rich-posts-bugs.trycloudflare.com/>**
**本地：<http://127.0.0.1:8790/>**

> 公网地址由 Cloudflare 快速隧道提供，隧道与本地服务由「登录自启」托管，关掉 DSH 应用也不影响。当前地址随时可从 `公网链接.txt` 读到；双击 `打开公网版.cmd` 会确保隧道在线并打开它。
>
> **注意**：快速隧道是临时的，**重启电脑后会换一个新地址**（新地址同样写在 `公网链接.txt` 里）。要一个永久不变的地址，见文末「固定地址」。

## 怎么打开

| 方式 | 操作 | 说明 |
| --- | --- | --- |
| 手机 | 打开上面的公网地址 | 在任意网络下都能看，建议加到手机主屏 |
| 公网启动 | 双击 `打开公网版.cmd` | 确保隧道在线，并打开公网地址 |
| 本地 | 双击 `打开资讯台.cmd` | 启动本地服务并打开浏览器 |
| 离线兜底 | 双击 `站点\index.html` | 不需要服务，任何浏览器都能看 |
| 订阅 | 阅读器里加 `http://127.0.0.1:8790/feed.xml` | 标准 Atom，支持往期 |

> 服务只监听本机与局域网，不对外网开放。同一 Wi-Fi 下的手机可访问 `http://<电脑IP>:8790/`（需在 Windows 防火墙放行 8790）。
>
> 应用退出或电脑重启后，本地服务会停止——双击 `打开资讯台.cmd` 即可恢复（页面文件本身始终在，`站点\index.html` 永远能直接打开）。

## 它是怎么"自动"的

| 环节 | 机制 | 状态 |
| --- | --- | --- |
| 每天 07:30 触发 | DeepSeek Harness 会话内的定时提醒 | ✅ 已设置 |
| 联网检索 + 写稿 | 由会话里的助手按 `每日生成手册.md` 执行 | ✅ |
| 生成网页 | `python build.py`（读 `数据\*.json` → `站点\*.html`） | ✅ |
| 推送 | 会话里直接给你三条要点 + 链接；同时生成 `推送\YYYY-MM-DD.txt` | ✅ |
| 手机/外网访问 | Cloudflare 快速隧道 + 登录自启（`zixun-service`） | ✅（地址会随重启变化） |

**关键限制**：定时提醒活在当前这个 DeepSeek Harness 会话里。电脑关机、应用退出时不会触发；应用重新打开后，提醒仍在。所以它是"打开电脑就有"，不是"服务器 7×24 推送"。

## 目录结构

```
资讯\
├─ 数据\            每天一份 JSON（内容的唯一来源）
├─ 站点\            生成的网页：index.html、往期、feed.xml
├─ 推送\            每天一份纯文本推送稿
├─ 资源\            style.css / app.js
├─ 工具\            cloudflared.exe 与隧道日志
├─ build.py         构建脚本
├─ serve.py         本地服务
├─ 每日生成手册.md   生成规范（给别人/别的智能体看的那份）
├─ 公网链接.txt      当前公网地址（隧道重启后会更新）
├─ 打开资讯台.cmd    本地一键启动 + 打开
├─ 打开公网版.cmd    确保隧道在线 + 打开公网地址
└─ 资讯台.url        书签式快捷方式
```

## 想改什么

- **改时间**：告诉我"改到 8 点"，我改会话里的定时提醒。
- **改栏目/篇幅**：编辑 `每日生成手册.md` 的"数量要求"与"写法要求"。
- **改样式**：`资源\style.css`，改完跑 `python build.py`。
- **加"晚报"**：见手册最后一节。
- **换端口**：`python serve.py --port 8800`，同时改 `build.py` 顶部的 `SITE_URL`。

## 固定地址（可选升级）

现在的公网地址是 Cloudflare 的**快速隧道**：不用注册，但每次重启电脑会换名字。如果希望手机书签永远不变，任选一条，我可以在几分钟内接好：

| 方案 | 你需要做的 | 结果 |
| --- | --- | --- |
| **Tailscale Funnel**（推荐） | 装 Tailscale、登录一次、在后台打开 Funnel | `https://<机器名>.<你的tailnet>.ts.net`，永久、无广告页、免费 |
| **ngrok 固定域名** | 注册 ngrok，把 authtoken 和免费 static domain 给我 | `https://xxx.ngrok-free.app`，永久（首次访问有一次提示页） |
| **自有域名 + Cloudflare** | 把域名托管到 Cloudflare，给我一个 Tunnel token | `https://news.你的域名`，最干净 |

不升级也完全可用：每天 07:30 的推送里会带上当时的公网地址，`公网链接.txt` 里也一直是最新的。
